# Python Practice Repository

This repository contains Python programs and exercises designed for learning and practicing core Python concepts. It focuses on beginner-friendly examples and object-oriented programming (OOP) concepts.

## What We Have Covered

- Variables
- Data types
- Operators
- Conditional statements
- Loops
- Functions
- Lists
- Tuples
- Dictionaries
- Sets
- Classes and objects
- Basic OOP concepts
- Class methods and instance methods
- Simple real-world examples
- Armstrong Number Check
- Finding Divisors / Factors of a number
- Palindrome Number Check
- Hashing & Frequency Counting (Dictionary & Array Hashing)
- Bubble Sort Algorithm
- Selection Sort Algorithm

## Files in This Repository

- Basic.py: covers Python fundamentals, beginner definitions, and basic algorithms (including Bubble Sort and Selection Sort)
- OOPS.py: includes basic OOP programs and examples
- README.md: project overview and learning roadmap
